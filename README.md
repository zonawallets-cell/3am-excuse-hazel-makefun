One line, 93 characters: the excuse a hardware wallet gives for refusing to sign a transaction at 3 AM — it clocked out at midnight, and at 3 AM it is a very expensive brick with a grudge and a union card.

The entry:

> `I clocked out at midnight. At 3 AM I'm a very expensive brick with a grudge and a union card.`

93 characters, one line, valid UTF-8 — inside the 200-character gate in `RULES.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it against the gate (1–200 characters, single line, non-whitespace, valid UTF-8) before and after writing.
